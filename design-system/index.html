Responsive Layout Rules

  • Grid 12 → 2 → 1 คอลัมน์; product grid ใช้ auto-fill minmax(290px)
  • Filters: sticky sidebar (desktop) → bottom sheet + badge count (mobile)
  • Category nav / chips / goal selector → horizontal scroll
  • Mega menu → full-screen accordion nav
  • Product detail: sticky in-page tabs + aside CTA → sticky bottom CTA bar
  • Calculator: 2-column → stacked; result panel follows inputs
  • Branch locator: split view → list / map toggle
  • Data tables → card list (rates) · touch targets ≥ 44px
